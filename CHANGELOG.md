# Changes

## 0.5.0

- Updated the mod for Steam 1.5.4 on Windows.
- Added compatibility with After the Storm's Siren Update 1.2. The 3 Player
  Mod uninstaller restores the installed Siren Update when both are present.

## 0.4.0

- Focus the package on three-player local co-op; remove unrelated gameplay changes.
- Simplify installation to **Install.cmd** and **Uninstall.cmd**.
- Add a short player guide and both three-player screenshots to the README.
- Keep the inventory handoff and saving fixes from the previous release.

## Earlier versions

- Fixed player two losing access to the shared inventory after changing character.
- Added inventory access for player three.
- Fixed a saving problem caused by the extra character.
- Added the third character and independent gamepad controls.
