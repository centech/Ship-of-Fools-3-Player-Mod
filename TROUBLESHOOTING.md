# Need help?

## The installer can't find the game

In Steam, right-click **Ship of Fools → Manage → Browse local files**. Extract
everything from the mod ZIP into that folder. **Install.cmd** should be beside
**ShipOfFools.exe**. Run it from there.

## Windows won't let the installer change the game

Close Ship of Fools first. If you still get an access error, right-click
**Install.cmd** and choose **Run as administrator**.

If Windows has blocked the download, right-click the downloaded ZIP, open
**Properties**, and select **Unblock** if that option appears. Extract it again.

## The third player doesn't appear

Connect the controllers before starting the game. Join two players normally and
enter the island, then press a face button on the spare controller. The extra
character starts in the same spot as player two, so move apart.

Each controller needs to appear as a separate controller to the game. If it
doesn't, check your Steam Input settings.

## Player two and three can't use the inventory together

They share one panel on the right, one person at a time. Press your own inventory
button to show your items. The other player can take it over with their button.
Player one has their own panel on the left.

## Player three's items disappeared between areas

Player three doesn't have a separate saved inventory. Put valuable items on the
ship before changing areas or quitting.

## The installer says my game isn't supported

Version 0.5.0 supports Windows Steam 1.5.4, including After the Storm's Siren
Update 1.2. If you are still on 1.5.3, use version 0.4.0. Other mods can affect
compatibility.

## There's a backup error

The installer keeps a backup beside the game files. If it can't recognize an
existing backup, it stops to avoid overwriting it. Keep that file safe and include
the exact error message when asking for help.

## I want to remove the mod

Close the game and run **Uninstall.cmd**. Steam's **Verify integrity of game
files** can also restore the game's current official files.

## Still stuck?

Open an issue with the error message, what you were doing and your controller
setup. A screenshot can help. Please don't upload game files or saves.
